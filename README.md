### Selected engineering work

- **Autonomous sailboat:** control, actuation, and motion planning, validated through field tests on Lake Ontario.
- **Marine sensor integration:** low-level NMEA 2000 / CAN drivers and a bridge into ROS for navigation data.
- **SolarStatus:** a Raspberry Pi dashboard for an EPEVER solar charge controller, built by reverse engineering its Modbus messages.
- **Parallel computing at Distributive:** co-developed a Python API and built C++ debugging tools for embedded JavaScript workers.
